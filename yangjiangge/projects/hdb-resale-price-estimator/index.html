NUS · IE1111R

HDB resale-price estimation tool

An Excel VBA tool combining cleaned HDB resale data, multiple linear regression, input forms and preference-based filtering.

Completed

Data & decision tools

01 / Context

The problem

Make historical HDB resale data easier to explore and use property and transaction attributes to generate an academic price estimate.

02 / Purpose

The objective

Combine a regression-based estimate with an Excel interface for entering attributes and filtering comparable resale records.

03 / Progress

Current status

Completed

The tool is described in the supplied resume as developed academic work. Prediction accuracy, public availability and real-world use are not established.

04 / Ownership

My contribution

Developed the Excel VBA tool, including data cleaning, pricing logic and the user interface, for IE1111R.

05 / Method

The approach

  • Organise raw and cleaned resale data, including transaction year/month, storey, floor area, lease commencement and location fields.
  • Use stored multiple-regression coefficients and an input-sheet calculation for the price estimate.
  • Use VBA UserForms to collect inputs and macros to filter resale records into saved result sheets.

06 / Evidence

What is available

  • The supplied macro-enabled workbook contains price-input, regression-output, raw/cleaned data, filtered-results and investment-results worksheets.
  • Static VBA inspection confirms input-form handlers, the estimate formula and filtering routines. Macros were not executed during this portfolio review.

07 / Looking ahead

Limitations & next steps

  • Add an approved screenshot of the running Excel interface and document the source-data period.
  • The stored regression summary measures in-sample fit; held-out prediction accuracy and macro runtime behaviour were not verified in this review.
  • The academic tool is not presented as a property valuation service.
