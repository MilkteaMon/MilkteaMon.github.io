Linear programming for operational planning

An operational planning model developed in Python using PuLP for Operations Research I.

Completed

Operational planning

01 / Context

The problem

Operational planning connects the decisions to be made with the limits they must satisfy. Linear programming expresses this relationship through decision variables, an objective and feasibility constraints.

02 / Purpose

The objective

Translate an operational planning problem into a linear-programming formulation that can be solved and interpreted in Python.

03 / Progress

Current status

Completed

Completed Operations Research I coursework model and final report, assessed at 27/30.

04 / Ownership

My contribution

Developed the model in Python using PuLP and prepared the course report.

05 / Method

The approach

  • Represent the planning decisions, linear objective and constraints in a mathematical model.
  • Implement the formulation in Python using PuLP.
  • Document the model and its interpretation in the Operations Research I course report.

06 / Evidence

What is available

  • IE2110 Operations Research I coursework: Python/PuLP model and final report. Report assessment: 27/30.

07 / Looking ahead

Limitations & next steps

  • An academic linear-programming model. Potential extensions include sensitivity to model parameters, uncertainty and decisions that require integer values.
